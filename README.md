# 🧠 Desafio DIO: Laboratório de Azure Speech Studio e Language Studio

## 📌 Objetivo
Este projeto tem como finalidade aplicar os conhecimentos adquiridos nas aulas da DIO sobre **Azure Speech Studio** e **Language Studio**, explorando suas funcionalidades para análise de fala e linguagem natural. A proposta é documentar a experiência prática e compartilhar insights relevantes para futuras implementações em IA.

## 🛠️ Ferramentas Utilizadas
- Azure Speech Studio
- Azure Language Studio
- GitHub
- Markdown

## 📚 Etapas Realizadas
1. Exploração do Speech Studio
2. Testes com Language Studio
3. Documentação técnica
4. Organização de capturas de tela
